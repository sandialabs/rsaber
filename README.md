rsaber
=======


This package implements the method *Sequential Adaptive Bayesian Estimation for Reliability* (SABER), which is a flexible Bayesian approach for modeling binary proportions across time. SABER handles both infinite- and finite-population cases, and can adaptively determine sample sizes or sampling rates to maintain a requirement.


### Installation


1. Download zip or tar.gz of package or clone repository
2. Install into R (> 4.3.0)

```
library("devtools")
install_github("sandialabs/rsaber")
```
